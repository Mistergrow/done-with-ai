# DONE WITH AI

**One human. AI as leverage. Real things shipped.**

I'm **Christopher Spitzner**, the creator behind DONE WITH AI. I build games
with AI assistance and publish playable results alongside records of the work.
This portfolio brings together game systems, visual assets, narrative, sound,
and the decisions needed to turn them into a finished experience.

## The projects

### 001 — Sommer '90

**Published · Godot · Free download / optional donation**

A narrative and management game about discovering home computers in the 1990s.
The released game is playable from beginning to end, as confirmed by its creator.
Its development combined game systems, visual asset work, narrative, and testing
with AI assistance.

[Download the game](https://misterfloppy.itch.io/sommer-90) ·
[Project record](projects/DWAI-001.md) ·
[Public source](https://github.com/Mistergrow/sommer-90)

The source is a release-correlated snapshot with MIT-licensed original code and
56 authorized replacement soundtrack tracks under CC BY 4.0. Some runtime assets
are excluded; the snapshot is **not a complete buildable distribution**. Use the
itch.io download to play.

### 002 — Bunkercrew

**In development · Godot · 2D cooperative bunker defense**

Mine resources, produce building materials, reinforce a bunker, and defend it
against machines: the intended experience centers on cooperation between the
players keeping the defenses supplied and those holding the line.

As of **5 October 2026**, I report the game as nearly finished. Its publication
status remains **development**; no public build is linked here yet.

## What DONE WITH AI documents

**IDEA → BUILD → TEST → SHIP → DOCUMENT → REPEAT**

The question behind this portfolio is how far one person can build across
disciplines with AI tools. Each project record separates the intended experience,
the published result, and the evidence available to inspect. Failures and
limitations belong in that record too.

My role is to set the direction, make product decisions, evaluate the results,
and decide what is ready to publish. AI assistance is part of the process;
responsibility for the published work stays with me. Historical measurements
that were not captured are marked as not recorded, rather than reconstructed.
