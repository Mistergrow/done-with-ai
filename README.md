# DONE WITH AI

One human. AI as leverage. Real things shipped.

DONE WITH AI explores how far one person can build across disciplines with
modern AI tools. The process is simple:

IDEA → BUILD → TEST → SHIP → DOCUMENT → REPEAT

Real projects and failures both count. This repository records what shipped,
what was learned, and what is being built next.
