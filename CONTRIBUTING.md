# Contributions

Contributions may be considered. Project feature development and fixes normally
belong in each project's canonical development repository, rather than in a
source snapshot held here.

For this repository, keep proposed documentation, registry, or publication-record
changes small and factual. Follow [GOVERNANCE.md](GOVERNANCE.md), identify the
relevant project ID, and include only material you have the right to share.
Do not include secrets, private information, or unreviewed third-party assets.

Christopher Spitzner reviews publication candidates. Submission does not
authorize publication or automatic merging, and no response time is promised.
Agents must not open issues or pull requests without explicit authorization.
