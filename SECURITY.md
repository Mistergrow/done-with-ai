# Responsible disclosure

Do not post credentials, private data, or exploitable vulnerability details in
public issues, pull requests, or discussions.

Use an explicitly approved private project contact or GitHub's private
vulnerability reporting facility if the affected repository offers it. No
private reporting contact has been approved for this foundation, and this setup
does not enable GitHub reporting features. If no private channel is available,
withhold sensitive details until an approved channel is established.

Reports should identify the affected project or publication, describe the impact,
and provide the minimum reproduction information needed. Never send live
credentials or unrelated personal data. No response time is promised.

Suspected secrets or private data in a publication candidate block publication.
Report the file and concern for human review without repeating the sensitive
value. Exposed credentials require human-reviewed remediation, including
revocation or rotation as appropriate, before publication can proceed.
