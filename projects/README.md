# Project publication records

Project identities and statuses live in [the registry](../registry/projects.json).
This directory is reserved for reviewed publication records, retrospectives,
and explicitly approved snapshots when needed. No source imports are included
in the initial foundation.

Develop projects in their separate development repositories. Prefer links to
canonical repositories and releases over duplicating their contents. Before
importing any snapshot, prepare the allowlist manifest and complete the review
and approval process in [GOVERNANCE.md](../GOVERNANCE.md).
